# CinemaModern

CinemaModern is a comprehensive web application designed to streamline cinema management operations. It offers a wide range of features for efficient planning, management, and promotion of film events.

## Introduction

CinemaModern is aimed at simplifying cinema management tasks, including film scheduling, ticket booking, and user management. It provides both administrators and end-users with intuitive interfaces for seamless interaction with cinema-related data and services.

## Features

- **Admin Dashboard:** Interface for managing film data, theater halls, screening schedules, users, vouchers, and other essential aspects of cinema operations.
- **Cinema Page:** Platform for end-users to browse movie listings, purchase tickets, use loyalty programs, and manage profiles.
- **Film Management:** Adding, editing, and deleting film information along with descriptions, posters, and other details.
- **Theater Hall Management:** Configuration and management of cinema halls, seat availability, and assigning films to specific halls.
- **Screening Schedule Planning:** Creating movie screening schedules, managing dates and times, and monitoring ticket availability.
- **Ticket and Voucher System:** Handling online ticket purchases, generating vouchers, and tracking purchase history.
- **Loyalty Program:** Implementation of a loyalty program for users with code generation capabilities.
- **External Integration:** Support for integrating with external payment services and login systems.

## Architecture

CinemaModern is built on a modular architecture, allowing flexible and independent deployment of individual components. The application consists of frontend and backend layers communicating via API interfaces, enabling easy scalability, extensibility, and maintenance.

## Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js with Express.js
- **Database:** MongoDB with Mongoose
- **Authentication and Security:** JWT Tokens, bcrypt
- **Other Technologies:** Redux, Sass
